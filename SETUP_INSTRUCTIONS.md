# Установка и запуск Jarvis

Актуализировано 8 сентября 2026 года. Полная инструкция по основному
Windows-приложению: [JARVIS_GUIDE_RU.md](JARVIS_GUIDE_RU.md).
Здесь — короткий маршрут установки; параметры, ограничения, примеры команд
и восстановление описаны в соответствующих разделах руководства.

## Если Jarvis уже установлен

Не клонируйте проект повторно и не заменяйте личный конфиг образцом.
Основная папка на ПК владельца: `C:\Users\user\Documents\Jarvis`.
Запуск — ярлык `J.A.R.V.I.S.` либо `launch_jarvis.bat` с консолью.
Папка Jarvis на рабочем столе относится к отдельному терминальному помощнику.

[Быстрый запуск и остановка](JARVIS_GUIDE_RU.md#quick-start).

## Новая установка на Windows

1. Подготовьте Python 3.10, Git, микрофон и вывод звука.
   Это проверенная версия Python, не универсальная гарантия совместимости.
2. Клонируйте `main` в новую папку, не поверх существующего проекта.
3. Установите `requirements.txt` тем же интерпретатором, которым будете
   запускать Jarvis. Для обычной установки владельца команды из корня проекта:

```powershell
$jarvisPython = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python310\python.exe'
& $jarvisPython --version
& $jarvisPython -m pip --version
& $jarvisPython -m pip install -r requirements.txt
```

4. Только при отсутствии `jarvis_config.json` скопируйте публичный образец:

```powershell
if (-not (Test-Path -LiteralPath '.\jarvis_config.json')) {
    Copy-Item -LiteralPath '.\jarvis_config.example.json' -Destination '.\jarvis_config.json'
}
```

5. Подготовьте LM Studio/Ollama и модель либо настройте облачный OpenRouter.
   Ключ облака не обязателен для локальной LLM. Заглушка из образца не работает:
   задайте настоящий ключ либо очистите его значение при закрытом Jarvis.
6. Подготовьте Whisper и выбранный голос. Piper требует локальные ONNX+JSON;
   Edge использует интернет. Выбор голосового движка сам не скачивает файлы Piper.
7. Выполните проверку и запустите приложение:

```powershell
& $jarvisPython -B health_check.py
& $jarvisPython -u jarvis.py
```

Прочитайте строки `MISS`/`FAIL` до запуска. Успешная последняя строка проверки
не доказывает доступность моделей, микрофона и внешних аккаунтов.
Не используйте случайную `.venv` только потому, что она существует.

## Настройки без перезапуска

Панель → изменить поля → **«Применить»** → дождаться **«Применено»**.
Текущая операция может сначала завершиться с прежними параметрами.
Закрытие панели не сохраняет правки; пустое поле ключа сохраняет старый секрет.
Переменные окружения имеют приоритет над JSON.

Ручные правки JSON автоматически не отслеживаются: делайте их при закрытом
Jarvis. Обновление Python-кода требует нового запуска; смена обычных настроек
из панели — нет. [Подробности применения](JARVIS_GUIDE_RU.md#live-settings).

Режим обзора проекта не записывает файлы и не запускает его код. Режим изменений
может выполнять тесты и shell с правами пользователя: это не песочница.
Облачные резервы и интеграции не отключаются одним выбором локальной модели.

Репозиторий содержит исходники, не личные настройки, модели, сессии и историю.

# Jarvis

**[Подробная инструкция по работе и настройке Jarvis](JARVIS_GUIDE_RU.md)** —
установка, первый запуск, интерфейс, модели, микрофон, голос, память, проекты,
Telegram/Google, диагностика, резервные копии и обновление. Актуализирована
8 сентября 2026 года для основной ветки `main`.

Мой голосовой помощник для Windows — что-то вроде домашнего "Джарвиса", только
по-русски и на моём компе Говоришь "Джарвис", он слушает, отвечает голосом и
делает, что просят: открывает программы и сайты, включает музыку, выполняет
команды в терминале, запускает Python, ведёт заметки, список дел и таймеры

Писал под себя, поэтому всё на русском и заточено под Windows

## Что понадобится

- Windows 10 или 11
- Python 3.10
- микрофон
- LM Studio или Ollama с локальной моделью; ключ [OpenRouter](https://openrouter.ai) нужен только для облачных ответов и резерва

## Установка

```powershell
git clone https://github.com/naturalniyaboba2077/JARVIS.git
cd JARVIS
py -3.10 -m pip install -r requirements.txt
if (-not (Test-Path -LiteralPath '.\jarvis_config.json')) {
    Copy-Item -LiteralPath '.\jarvis_config.example.json' -Destination '.\jarvis_config.json'
}
```

Дальше настрой выбранный сервер модели и голос. Ключ `OPENROUTER_API_KEY`
нужен только для облачных ответов и резерва. Заглушку из образца замени своим
ключом либо очисти при закрытом Jarvis, если облако не нужно. Пустое секретное
поле в GUI сохраняет старый ключ, а не удаляет его. Личный конфиг исключён из Git.
Используй один и тот же Python для установки, тестов и запуска; подробности
про штатные ярлыки и интерпретатор — в руководстве.

## Запуск

```powershell
py -3.10 jarvis.py
```

Окно открывается до загрузки голосовых модулей и модели. Во время запуска можно
набрать команду; отправка станет доступна после готовности ядра, без потери
черновика и без автоматического выполнения. Замеры, ограничения и проверка
скорости описаны в [STARTUP.md](STARTUP.md).

Параметры из панели настроек применяются кнопкой **«Применить» без перезапуска
Jarvis**. Текущий ответ завершается с прежними параметрами; состояние применения
видно в панели. Возможности и ограничения — в [LIVE_SETTINGS.md](LIVE_SETTINGS.md).

Проектные и явно запрошенные письменные отчёты остаются в чате, вслух звучит
короткий итог. Команда **«прочитай отчёт»** озвучивает последний отчёт без повторной
проверки. Разметка и кавычки в TTS очищаются. Подробности — [VOICE_REPORTS.md](VOICE_REPORTS.md).

«Посмотри проект …» запускает обзор без изменений. После выбора проекта можно
сказать «проверь его и оцени»: имя повторять не обязательно, если выбор ещё
актуален и однозначен. Если найден похожий проект, Jarvis спросит **«Это тот проект?»**:
нажмите «Да, этот проект» / «Не тот» или ответьте голосом. Подтверждение продолжит
исходное поручение; при нескольких вариантах выберите кнопку или назовите номер.
Примеры и границы — [CONVERSATION_UX.md](CONVERSATION_UX.md).

### LM Studio

Связный диалог, долговременная память и дружеские подколы описаны в
[DIALOGUE_MEMORY.md](DIALOGUE_MEMORY.md). Настройка «Память между запусками»
сохраняет контекст локально; обычные «да», «нет» и «несмешно» продолжают беседу.

Для локальной модели через LM Studio запустите Local Server с OpenAI-compatible
API на `http://127.0.0.1:1234/v1` и загрузите совместимую модель из своей библиотеки.
Укажите её точный серверный ID в настройках. В публичном образце выбран режим
`"JARVIS_LLM": "lmstudio"`; обычные запросы используют
`LM_STUDIO_MODEL`, а запросы с кодом, терминалом или исследованием —
`LM_STUDIO_CODE_MODEL`. По умолчанию это один и тот же model ID. Если Local
Server не выдаёт первый токен за 30 секунд, Jarvis пробует Ollama, затем
OpenRouter при наличии ключа. Для холодного старта Ollama выделено 40 секунд:
на проверенном ПК загрузка весов заняла около 25 секунд. Это предел ожидания,
а не обязательная задержка каждого ответа. `LM_STUDIO_AUTOLOAD=on` разрешает
загрузить настроенную модель через `lms` при отсутствии загруженной модели;
сам Local Server должен быть запущен.

Исправления распознавания поручений, настройки голоса и проверенные сценарии —
в [REQUEST_ROUTING_FIXES.md](REQUEST_ROUTING_FIXES.md). Голос в публичном образце —
русский Edge DmitryNeural, темп `-5%`, высота `-10Hz`: стилизация, не точный голос из фильма.
Edge передаёт текст озвучивания Microsoft и требует интернет. Для офлайн-озвучивания
можно выбрать установленный Piper.

Говоришь «Джарвис, …» вместе с командой. После отдельного «Джарвис» открывается
тихое окно ожидания продолжения — голосового «Слушаю» ждать не нужно.

## Если нет видеокарты и не хочется ставить модели

Для облачных ответов, распознавания и голоса задай три параметра ниже и рабочий
ключ OpenRouter. Это фрагмент для объединения с личным конфигом, не замена файла:

```json
{
  "JARVIS_LLM": "cloud",
  "STT_ENGINE": "google",
  "TTS_ENGINE": "edge"
}
```

Модели для основных облачных маршрутов не требуются, но Python-зависимости
самого приложения всё равно нужны. Ollama остаётся возможным резервом, если
установлена и настроена. Для локальных компонентов подготовь Ollama/LM Studio,
Whisper и Piper; выбор локального режима сам не запрещает сетевые резервы.
Подробности — в [инструкции](JARVIS_GUIDE_RU.md#models).

## Работа с проектами

Для сложной разработки используется выбранный модельный backend: локальный
LM Studio/Ollama или OpenRouter в облачном режиме. «Проверь проект» означает
обзор без записи и запуска кода. Явное поручение на изменения позволяет агенту
вносить версионированные правки и выполнять поддерживаемые проверки.
Пример:

`Джарвис, поработай над проектом Jarvis: исправь ошибку запуска и проверь синтаксис`

Каждая правка агента сохраняет прежнее содержимое файла, поэтому её можно
отменить: «Джарвис, отмени последнюю правку в проекте Jarvis» или «покажи
правки в проекте Jarvis». История лежит рядом с Джарвисом, а не внутри вашего
проекта, и в гит не уходит; путь можно сменить через `JARVIS_FILE_HISTORY`.

В режиме порученных изменений Jarvis может запускать через проектного агента
shell-команды, тесты и Git из корня проекта. Это запуск на
основном компьютере, а не песочница: `cwd` не ограничивает процесс, а изменения
от `run_command` не попадают в историю undo. Anti-wipe фильтр задерживает часть
очевидно разрушительных операций, но не гарантирует защиту от любого вреда.
Прямые пользовательские `CMD` и `EXECUTE_PYTHON` также не становятся песочницей.
Понимание поручения и качество ответа зависят от модели; отсутствие любых отказов
и ошибок не гарантируется.

Откат сверяет содержимое и идентичность файла: ручная правка, подмена ссылкой
или утрата резервной копии вызывают конфликт вместо удаления чужих данных.
Незавершённая операция восстанавливается из журнала при следующем обращении.
Старые записи без отпечатка результата сохраняются, но автоматически не откатываются.

Разрешённые каталоги задаются через `JARVIS_PROJECT_ROOTS` (несколько путей через
`;`). `OPENROUTER_AGENT_MODEL` выбирает агента только в облачном режиме;
в локальных используются их настройки. ID `openrouter/free` не гарантирует
постоянную доступность и достаточную квоту. После версионированной записи
приложение выполняет поддерживаемые проверки исходников и обнаруженных тестов;
при отсутствии тестов или зависимостей сообщает ограничение, а не полный успех.
Подробный порядок выбора, изменений и отката — в
[руководстве](JARVIS_GUIDE_RU.md#projects).

## Тесты

Полный набор регрессий запускается в одноразовой копии исходников, без личных
конфигов, сессий и заметок, с заблокированной внешней сетью и подставным буфером:

```powershell
python -B run_tests.py
```

Один набор: `python -B run_tests.py test_audit_actions.py`.
Не запускайте старые `test_*.py` напрямую рядом с личными данными: некоторые
проверки используют штатные функции сохранения/очистки сессионной памяти.

`test_portability.py` следит за тем, чтобы ядро оставалось переносимым: оно
должно импортироваться на домашнем сервере под Linux, где нет ни `pyautogui`,
ни `pycaw`, ни графического дисплея. Всё, что умеет только Windows, живёт в
`jarvis_platform.py` и на других платформах возвращает честный отказ вместо
падения.

## Из чего всё состоит

- `jarvis.py` — ядро: диспетчер тегов, работа с моделью, главный цикл и окно-мост
- `jarvis_actions.py` — однопроходный разбор и проверка команд без побочных действий;
  результаты инструментов не разбираются повторно, повторные теги выполняются по порядку
- `jarvis_config.py` — настройки, пути, версия; подключается первым
- `jarvis_log.py` — технический журнал в `logs/`, имя файла выбирается при запуске
- `jarvis_state.py` — то, что видят сразу несколько модулей: ожидающие
  подтверждения отправки и метрики задержек
- `jarvis_platform.py` — всё, что умеет только Windows: громкость, media-клавиши,
  яркость, блокировка. Ядро обращается только сюда, поэтому переносится на Linux
- `jarvis_llm.py` — LM Studio, Ollama и OpenRouter, бюджеты времени и резервы
- `jarvis_telegram.py` — личный аккаунт Telegram и поиск профиля
- `jarvis_features.py` — окна, буфер обмена, напоминания, файлы, OCR, почта
- `jarvis_apps.py` — каталог установленных программ и разбор «открой …»
- `jarvis_notes.py` — заметки Obsidian, долговременная память
- `jarvis_store.py` — личная память, список дел, таймеры
- `jarvis_tts.py` — синтез речи: Piper, edge-tts, кэш фраз
- `jarvis_stt.py` — распознавание и слово активации
- `jarvis_tools.py` — сами действия: погода, программы, терминал, код, скриншот
- `jarvis_safety.py` — фильтр разрушительных команд, общий для ядра и агента
- `jarvis_fileops.py` — версионирование правок и откат
- `jarvis_mail.py` — почта и календарь Google
- `jarvis_lookup.py` — поиск по юзернейму и номеру
- `jarvis_ui.py` — окно и управление отдельным индикатором речи
- `project_agent.py` — работа с кодом проектов через модель
- `jarvis_project_context.py` — краткий контекст выбранной папки для новых явных просьб проверить её
- `jarvis_project_selection.py` — одноразовый выбор похожего проекта кнопкой, голосом или текстом с продолжением исходной задачи
- `jarvis_project_checks.py` — ограниченные проверки синтаксиса и поиск без host-shell
- `overlay.py` — отдельная капсула речи при свёрнутом окне
- `ui/` — разметка окна
- `pc_apps.txt` — список установленных программ, по нему работает "открой …"
- `install_shortcut.ps1` — делает ярлык на рабочем столе

Ответы модели с возможными действиями сначала проверяются целиком, затем
выполняются и озвучиваются по фактическому результату. Они могут начинать
звучать позже обычного разговора, который остаётся потоковым. «Джарвис стоп»
или `стоп` в панели прерывает Python и текущий голосовой ответ.
Таймеры/напоминания получают новую область отмены и не теряются после прежнего
прерывания. Текстовый аргумент с несбалансированными скобками передаётся
JSON-строкой, например `[TYPE:"Интервал (0, 1] полуоткрытый."]`.

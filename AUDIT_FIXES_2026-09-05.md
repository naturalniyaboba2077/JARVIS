## Границы результата

- Изолированный backend для исполнения тестов проектным агентом не установлен.
  Он не обещает запустить их и не откатывается к shell на основном компьютере.
  `run_tests.py` предназначен для доверенных тестов Jarvis, не для недоверенного кода.
- Прямые пользовательские CMD/Python — прежняя anti-wipe эвристика, **не sandbox**.
  Вычисляемый произвольным кодом путь нельзя надёжно ограничить статическим фильтром.
- Старые журналы и резервные копии сохранены. Автоматический откат старой записи
  без доказуемого контрольного состояния отклоняется; возможен ручной разбор копии.
- Защита файлов не изолирует от враждебного процесса с теми же правами пользователя.
  Каталог истории должен быть доверенным. Полная устойчивость к потере питания
  зависит от файловой системы; Windows не предоставляет переносимый directory fsync.
- Заблокированный нативный вызов нельзя принудительно убить как Python-поток.
  Ожидания очереди отменяются, поздний результат отбрасывается, внешние транспорты
  имеют таймауты. Это не гарантия немедленного завершения любого драйвера/синтезатора.
- Реальный микрофон, звучание голоса, живые LLM-провайдеры и отправка сообщений
  после этих изменений не проверялись. Они требуют отдельного живого smoke-test.
- Личные конфиги, сообщения, контакты, заметки и реальные истории не изменялись.
  При исходном исправлении проект не коммитился и не отправлялся на сервер.
  Последующая публикация в Git выполняется по отдельному поручению пользователя;
  приложение автоматически не перезапускалось.
- Новые продуктовые функции из рекомендаций аудита в эту правку не входят.
